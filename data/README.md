# Dados do desafio

Os dados distribuídos permanecem em `../material_desafio_jusbrasil_bracis/`:
o SQLite `desafio1_bracis.db`, o `goldenset.csv`, o `kaggle_metric.py`, o
`sample_submission.csv` e os textos em `txt/`.

Eles não são copiados para este diretório, evitando duplicação do banco. Neste
bootstrap, o SQLite deve ser aberto exclusivamente em modo read-only pela API
de `bracis_jusbrasil.database`.
